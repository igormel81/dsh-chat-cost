# Promotion texts

Ready-to-use copy for the channels this plugin can be promoted on, in the language each channel actually reads. Nothing here is posted automatically: it is written so a human can paste it and go.

| File | Where it goes | Language | When |
| --- | --- | --- | --- |
| `awesome-pr.md` | pull request to `awesome-dsh-plugin/awesome-dsh-plugin` | English | **available now** — the repo passed one day old on 2026-09-13T18:14:28Z |
| `plugin-store-issue.md` | issue in `Ericwong5021/deepseek-plugin-store` (1,732 plugins) | English | now |
| `readme-screenshot.md` | the three READMEs, once a screenshot exists | en / zh / ru | before the launch posts |
| `show-hn.md` | Hacker News, `Show HN` | English | after the awesome-list PR merges |
| `reddit.md` | r/LocalLLaMA, r/DeepSeek, r/LLMDevs | English | same day as HN, spaced a few hours |
| `x-thread.md` | X/Twitter | English | same day |
| `telegram.md` | Russian DSH/AI chats and channels | Russian | same day |
| `article.md` | Habr (ru) or dev.to (en) — a technical write-up | ru (outline for en) | within the first week |

Rules these texts follow, because a promotion that oversells costs more than it earns:

- every number is checkable in the repository (`data/prices.json`, `lib/`, `test/`);
- the honest limits are stated in the same breath as the features — the plugin prices what it can prove;
- no claim about quality, popularity, or being "the best"; there is no quality score in the catalog and none is invented here;
- the neighbour plugins in the same niche are named rather than ignored, so a reader can compare.
